**版本：V1.0**
**日期：2026-07-09**

## 1. OWASP Top 10 评估

| 威胁 | 风险等级 | 当前防护措施 | 缺口 |
|:---|:---:|:---|:---|
| A01 权限控制失效 | 高 | RBAC + 行级数据隔离 + DRF Permission | 需定期审计权限配置 |
| A02 加密机制失效 | 中 | HTTPS + JWT + 密码哈希 | - |
| A03 注入 | 高 | ORM 参数化查询 + SC-3 规则 | - |
| A04 不安全设计 | 中 | 宪法级规则 + 安全红线契约 | - |
| A05 安全配置错误 | 中 | 环境变量注入 + SC-1 规则 | 需禁用 DEBUG/ALLOWED_HOSTS=* |
| A06 脆弱过时组件 | 中 | SC-7 依赖审计 + pip-audit/npm audit | - |
| A07 认证失效 | 高 | JWT + 密码策略 + 令牌刷新 | 需增加登录失败锁定 |
| A08 数据完整性 | 中 | 乐观锁 + @transaction.atomic | - |
| A09 日志监控不足 | 中 | OC-1~OC-3 可观测性契约 | 需增加实时告警 |
| A10 SSRF | 低 | 无外部请求功能 | - |

## 2. 敏感数据分级

| 级别 | 定义 | 示例字段 | 处理要求 |
|:---|:---|:---|:---|
| L1 机密 | 泄露导致重大损失 | password, JWT secret | 加密存储，不可回显，日志禁止记录 |
| L2 敏感 | 泄露导致合规风险 | asset_purchase_price, employee_phone | API 脱敏，日志脱敏，前端按权限显示 |
| L3 内部 | 仅限内部使用 | asset_code, department_name | 不对外暴露，需认证访问 |

## 3. 数据脱敏规则

### 3.1 日志脱敏

| 字段 | 脱敏方式 | 示例 |
|:---|:---|:---|
| password | 禁止记录 | [FILTERED] |
| auth_phone | 保留前3后4 | 138****5678 |
| email | 保留首字母和域名 | z***@example.com |
| asset_purchase_price | 非管理员禁止记录 | [REDACTED] |
| JWT token | 禁止记录 | [FILTERED] |

### 3.2 API 响应脱敏

| 接口 | 字段 | 脱敏规则 |
|:---|:---|:---|
| 资产列表 | asset_purchase_price | 非管理员角色返回 "****" |
| 员工详情 | employee_phone | 非管理员角色返回 "138****5678" |
| 用户详情 | email | 非本人/管理员返回 "z***@example.com" |
| 扫码查看 `/public/scan/` | asset_purchase_price | 无认证用户返回 "****" |
| 扫码查看 `/public/scan/` | employee_phone（保管人） | 无认证用户返回 "138****5678" |

### 3.3 前端脱敏

| 场景 | 处理方式 |
|:---|:---|
| 资产价格列 | 非授权用户显示 "****" |
| 员工手机号 | 鼠标悬停显示完整号码 |
| 密码字段 | 始终显示为 `••••••••` |

## 4. 安全基线检查清单

- [ ] 所有接口使用 HTTPS
- [ ] CORS 仅允许指定域名
- [ ] DEBUG=False in production
- [ ] SECRET_KEY 从环境变量注入
- [ ] 数据库密码不硬编码
- [ ] 文件上传校验扩展名 + MIME + 大小
- [ ] 上传文件名重命名为 UUID
- [ ] SQL 查询全部参数化
- [ ] 依赖漏洞扫描通过（CVSS < 7.0）
- [ ] 登录失败 5 次后锁定 15 分钟
- [ ] 敏感操作日志完整
- [ ] 审计日志不可删除
