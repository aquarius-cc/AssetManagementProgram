**日期：2026-07-09**

## 1. 导入规范

### 1.1 支持导入的模块

| 模块 | 导入内容 | API 端点 |
|:---|:---|:---|
| 资产 | 批量创建资产 | POST /assets/batch-create/ |
| 资产类型 | 批量创建类型 | POST /asset-types/batch-create/ |
| 仓库 | 批量创建仓库 | POST /storages/batch-create/ |
| 合同 | 批量创建合同 | POST /contracts/batch-create/ |
| 部门 | 批量创建部门 | POST /departments/batch-create/ |
| 员工 | 批量创建员工 | POST /employees/batch-create/ |

### 1.3 导入规则

| 规则 | 说明 |
|:---|:---|
| 单次上限 | 每次最多导入 **500 条**记录 |
| 文件格式 | .xlsx（Excel 2007+），不支持 .xls |
| 文件大小 | ≤ 10MB |
| 编码 | UTF-8 |
| 空行处理 | 自动跳过空行 |
| 重复检测 | 同一文件内 asset_name + asset_type 不允许重复 |
| 错误处理 | 逐行校验，失败行跳过并记录错误，成功行继续处理 |
| 响应格式 | 返回成功条数、失败条数、每行失败原因 |

### 1.4 导入响应示例

```json
{
  "code": 0,
  "message": "导入完成：成功 48 条，失败 2 条",
  "data": {
    "total": 50,
    "success_count": 48,
    "fail_count": 2,
    "errors": [
      {"row": 12, "reason": "资产类型编码 'PHONE' 不存在"},
      {"row": 35, "reason": "购买单价不能为空"}
    ]
  }
}
```

## 2. 导出规范

### 2.1 支持导出的模块

| 模块 | 导出内容 | API 端点 |
|:---|:---|:---|
| 资产列表 | 当前筛选条件下的所有资产 | GET /assets/export/ |
| 出库记录 | 当前筛选条件下的出库记录 | GET /out-assets/export/ |
| 回收记录 | 当前筛选条件下的回收记录 | GET /recycle-assets/export/ |
| 审计日志 | 指定时间范围的审计日志 | GET /asset-logs/export/ |

### 2.2 导出字段

**资产导出字段**（全部导出，敏感字段脱敏）：

| 字段 | 脱敏规则 | 说明 |
|:---|:---|:---|
| asset_code | 不脱敏 | 资产编码 |
| asset_name | 不脱敏 | 资产名称 |
| asset_purchase_price | 非管理员显示为 "****" | 购买价格（脱敏） |
| asset_current_status | 不脱敏 | 当前状态 |
| asset_manager_recordcode | 不脱敏 | 保管人 |
| 其他字段 | 不脱敏 | - |

### 2.3 导出规则

| 规则 | 说明 |
|:---|:---|
| 文件格式 | .xlsx |
| 文件大小限制 | ≤ 5000 条，超过时提示"数据量过大，请缩小筛选范围" |
| 生成方式 | 异步生成，前端轮询下载链接 |
| 保留期限 | 导出文件保留 24 小时后自动清理 |
