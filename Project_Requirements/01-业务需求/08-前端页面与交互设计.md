## 1. 页面清单与路由规划

> **路由参数说明**：Vue Router 中 `:recordcode` 表示动态路由参数，`:` 前缀是 Vue Router 的语法标记，表示该段 URL 是可变的。例如 `/assets/ASSET-20260708-A3F9B2E1` 会匹配 `/assets/:recordcode`，其中 `recordcode` 的值为 `ASSET-20260708-A3F9B2E1`。使用 `recordcode` 而非 `code` 是因为系统中 recordcode 是所有模型的全局唯一主键。

**交互规则**：
- **多字段搜索**：顶部搜索栏支持按资产编码、名称、规格、品牌（文本输入模糊匹配）+ 资产类型、状态、仓库、使用性质（下拉框精确匹配）组合筛选，各条件之间为 AND 逻辑
- **重置**：点击"重置"清空所有搜索条件，恢复默认列表
- **序号列**：自动编号，跟随分页（第 1 页 1-20，第 2 页 21-40）
- **复选框**：支持单选和全选（表头复选框），选中后高亮行，显示"已选 N 条"
- **批量删除**：选中条目后点击"批量删除"，弹出二次确认："确认删除选中的 N 条资产？删除后不可恢复"
- **状态列**：使用 `StatusTag` 彩色标签展示，不可点击
- **操作列**：
  - "详情" → 跳转资产详情页
  - "编辑" → 跳转编辑页（仅 in_store 状态可编辑）
  - "删除" → 二次确认后软删除（仅 in_store 状态可删除）
  - 已报废资产操作列仅显示"详情"
- **列排序**：点击列头可按该列升序/降序排序，再次点击切换排序方向

### 2.1A 资产列表页 · 分组展开视图

> **启用方式**：分组能力由开关 `enableGrouping` 控制，**默认关闭**。关闭时列表渲染行为与 §2.1 现状**零差异**（保证既有页面不受影响）。本期仅作用于资产台账。

**布局（汇总区 + 明细区）**：
```
┌──────────────────────────────────────────────────────────────────────────────────┐
│  资产管理  [启用分组 ☑]                                                [新增资产]│
├──────────────────────────────────────────────────────────────────────────────────┤
│  （沿用 §2.1 搜索栏：编码/名称/规格/品牌 + 类型/状态/仓库/使用性质）        │
├────┬────┬────────┬────────────┬──────────┬────────┬──────┬───────────────────────┤
│ ☑  │ 序号│ 合同号 │ 资产名称    │ 型号规格 │ 单价    │ 数量 │ 操作                  │ ← 汇总行
├────┼────┼────────┼────────────┼──────────┼────────┼──────┼───────────────────────┤
│ ☐  │ 1  │ HT00001│ 笔记本电脑 │ 14寸/i5  │4,500.00│  3   │ 编辑 删除 详细         │ ← 汇总行
│    │ ▼  ├────────┼────────────┼──────────┼────────┼──────┼───────────────────────┤
│    │ 1  │ HT00001│ ThinkPad   │ 14寸/i5  │4,500.00│  1   │ 详情                  │ ← 明细行
│    │ 2  │ HT00001│ ThinkPad   │ 14寸/i5  │4,500.00│  1   │ 详情                  │
│ ☑  │ 2  │ —      │ 办公桌     │ 标准     │ 800.00 │  2   │ 编辑 删除 详细         │ ← 哨兵汇总行
├────┴────┴────────┴────────────┴──────────┴────────┴──────┴───────────────────────┤
│  共 120 组  < 1 2 3 ... 6 >  每页 [20▼]    组内：< 1 2 >  每页 [20▼]         │
└──────────────────────────────────────────────────────────────────────────────────┘
```

**汇总区 8 个数据列**：合同号、资产名称、型号规格、品牌、单价、数量（`asset_count`）、唯一记录码、资产分类。
**明细区 10 个数据列**：唯一记录码、编码、名称、型号规格、品牌、资产分类、当前状态、合同号、单价、**实物数量**。

**交互规则**：

- **分组键**：由 `contract_code` + `资产名称` + `型号规格` + `品牌` 四元组构成，任一维度不同即分入不同组
- **单价列（汇总行）**：组内单价一致时显示单值（如 `4,500.00`）；不一致时显示区间（如 `4,500.00~5,000.00`，两位小数、升序）
- **数量列**：汇总行为该组资产条数 `asset_count`（COUNT 口径）；明细行为**实物数量**，**每行恒显 1**（渲染常数，不绑定 `asset_purchase_number`，见术语表）
- **无合同资产**：归入哨兵组，合同列显示 `—`；排序主键为数量降序，**仅在数量相同时**该组排在所有有合同分组之后（前端不得假设哨兵组恒在末位）
- **展开/收起**：点击汇总行的展开箭头切换明细区；同一时刻可展开多个组
- **单条组自动展开**：`asset_count == 1` 的组在首次加载时**自动展开**，无需手动点击；`asset_count > 1` 的组不自动展开
- **展开态不持久化**：展开/收起状态仅存于内存，页面刷新后恢复默认；切换筛选条件或翻动汇总页时该状态重置
- **懒加载缓存**：明细区首次展开时才请求数据；同一组再次展开时命中缓存**零请求**；仅组内翻页或筛选变更时重新拉取
- **组内分页**：仅当 `asset_count > 100` 时在组底部显示组内分页条；`page_size` 默认 20、上限 100；翻页为**追加**渲染（不清空已加载明细）
- **级联勾选**：
  - 勾选汇总行 = 按该组 `asset_codes` **全量选中**其全部明细
  - 组内仅部分选中时，汇总行显示**半选**（indeterminate）态
  - 在明细区勾选单条时，所属汇总行状态**反向同步**
  - 汇总与明细两侧的选择键统一为 `asset_code`
- **冻结列**：列宽超出容器时横向滚动，**勾选列与序号列冻结在左侧、操作列冻结在右侧**
- **序号双口径**：汇总行序号与明细行序号各自独立编号（明细序号在组内从 1 开始）
- **排序**：按 `asset_count` 降序；数量相同时合同号升序且**空值置末**；其后依次按资产名称、型号规格、品牌，保证翻页稳定
- **操作文案**：汇总行与明细行均为「编辑 / 删除 / 详细」
- **筛选透传**：展开明细时必须原样透传当前筛选参数与该组 `group_key`，否则明细数会与汇总 `asset_count` 不一致

### 4.1 术语表

> ⚠️ **「录入数量」与「实物数量」是两个不同概念，任何界面文案不得混用。** 二者混淆是本特性最易产生的用户误解（录入 3 台看起来像 9 台）。

| 术语 | 界面文案 | 数据来源 | 语义 | 出现位置 |
|:---|:---|:---|:---|:---|
| **录入数量** | 录入数量 | create 入参 `asset_purchase_number` | **录入倍数 N**：一次提交要求生成几台资产。**瞬态**，仅决定 fan-out 条数，**不作为行数据落库** | 新增/编辑表单、批量导入模板与导入表头 |
| **实物数量** | 实物数量 | **无数据源，为渲染常数 1** | 每条资产明细行代表的**实物台数恒为 1**。**禁止**绑定 `asset_purchase_number` | 资产台账明细区、**导出列** |
| 资产条数 | 数量 | 汇总行 `asset_count`（COUNT 口径） | 该分组的资产明细**行数** | 分组视图汇总行 |

**恒等式（必须成立）**：

```
asset_count（汇总条数） ≡ Σ 明细实物数量 ≡ Σ 1 ≡ 录入倍数 N
```

即：录入 3 台 → 落库 **3 条**明细，每条实物数量 **1**，汇总 `asset_count` = **3**，导出 **3 行**且实物数量恒为 1。

> **反例警示**：若明细数量列绑定 `asset_purchase_number`，录入 3 台时每行显 3，3 台实物看起来像 9 台 —— 比不显示更糟。因此明细列**只渲染常数 1**。
