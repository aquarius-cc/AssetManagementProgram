## 1. 系统登录

### 1.1 访问地址
- 生产环境：https://app.example.com
- 测试环境：https://test-app.internal

### 1.2 登录步骤
1. 打开浏览器，输入系统地址
2. 输入用户名和密码
3. 点击"登录"
4. 首次登录建议修改初始密码

### 1.3 常见问题
- **忘记密码**：联系系统管理员重置
- **登录后自动退出**：Access Token 有效期 2 小时，系统会自动刷新；若长时间未操作，需重新登录

## 2. 资产管理员操作指南

### 2.1 创建新资产
1. 进入"资产管理" → 点击"新增资产"
2. 选择资产类型（必填）
3. 填写资产名称、品牌、规格、价格等信息
4. 选择仓库、入库人员
5. 点击"保存" → 系统自动生成资产编码

### 2.2 资产出库（领用/借用）
1. 在资产列表中找到目标资产 → 点击"详情"
2. 点击"出库"按钮
3. 选择出库类型（领用或借用）
4. 选择申请人和保管人
5. 填写使用地点
6. 如果是借用，填写预计归还日期
7. 点击"确认出库" → 二次确认弹窗 → 确认

### 2.3 资产回收
1. 在资产详情页点击"回收"
2. 确认回收信息
3. 如果发现损坏，勾选"存在损坏"并填写原因
4. 点击"确认回收"

### 2.4 标记损坏/遗失
1. 在资产详情页点击"标记损坏"或"标记遗失"
2. 填写原因和详细描述
3. 确认提交

### 2.5 维修管理
1. 在资产详情页（损坏状态）点击"送修"
2. 填写维修原因、预计完成日期
3. 维修完成后，点击"维修完成"，填写维修后成色
4. 如果维修失败，点击"维修失败"

### 2.6 申请报废
1. 在资产详情页点击"申请报废"
2. 填写报废原因
3. 提交后等待部门经理审批

## 3. 部门经理操作指南

### 3.1 审批报废申请
1. 进入"报废审批"页面
2. 查看待审批列表
3. 点击资产查看详情和报废原因
4. 点击"审批通过"或"审批拒绝"
5. 拒绝时需填写拒绝原因

### 3.2 审批未登记资产
1. 进入"未登记资产"页面
2. 查看待审批的未登记资产
3. 选择处理方式（入库/报废/退回）
4. 确认审批

## 4. 审计员操作指南

### 4.1 查看审计日志
1. 进入"资产管理" → 选择资产 → 点击"状态日志"
2. 查看该资产的完整状态变更历史
3. 支持按时间范围筛选

---

## 5. 二维码扫码查看

### 5.1 如何查看资产二维码
1. 进入资产详情页
2. 页面右侧显示该资产的二维码
3. 点击"下载二维码"可保存为 PNG 图片
4. 点击"打印"可打印二维码标签

### 5.2 如何用手机扫码
1. 打开手机相机或微信扫一扫
2. 对准资产上的二维码
3. 自动跳转到资产详情页面（无需登录）
4. 可查看资产编码、名称、类型、状态、保管人、使用地点等基本信息
5. 价格和联系电话等敏感信息已自动脱敏

## 6. 常见问题 FAQ

| 问题 | 解决方案 |
|:---|:---|
| 找不到某个资产 | 使用搜索框按编码或名称搜索，或使用多条件筛选 |
| 操作时提示"当前状态不允许" | 检查资产当前状态，确认操作是否合法 |
| 操作时提示"资产已被其他用户操作" | 刷新页面后重试 |
| 批量导入失败 | 检查 Excel 模板格式，确认必填字段和编码正确 |
| 导出的文件打不开 | 确认使用 Excel 2007+ 打开 .xlsx 文件 |
