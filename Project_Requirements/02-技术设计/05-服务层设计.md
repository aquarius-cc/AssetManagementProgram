## 1. 分层架构

系统采用 **View → Service → Selector → Serializer → Model** 五层单向依赖架构：

```markdown
┌─────────────────────────────────────────────────────────────┐
│ View 层（DRF ViewSet） │
│ - 接收HTTP请求，参数解析、权限校验 │
│ - 调用Service层处理业务逻辑 │
│ - 使用Serializer进行数据序列化/反序列化 │
└─────────────────────────────────────────────────────────────┘
│ 依赖
▼
┌─────────────────────────────────────────────────────────────┐
│ Service 层（业务逻辑层） │
│ - 编排核心业务流程（出库、回收、报废等） │
│ - 控制事务边界（@transaction.atomic） │
│ - 调用状态机（AssetFSM）更新资产状态 │
│ - 调用Selector层进行数据查询 │
│ - 创建关联业务记录和状态变更日志 │
│ - 处理并发锁（select_for_update） │
└─────────────────────────────────────────────────────────────┘
│ 依赖
▼
┌─────────────────────────────────────────────────────────────┐
│ Selector 层（数据查询层） │
│ - 封装复杂查询逻辑（JOIN、子查询、聚合） │
│ - 应用行级数据隔离（按部门过滤） │
│ - 处理排序、分页、过滤条件 │
│ - 返回QuerySet或预取数据 │
└─────────────────────────────────────────────────────────────┘
│ 依赖
▼
┌─────────────────────────────────────────────────────────────┐
│ Serializer 层（序列化器层） │
│ - 模型数据与JSON格式的双向转换 │
│ - 请求数据反序列化与验证 │
│ - 响应数据序列化 │
└─────────────────────────────────────────────────────────────┘
│ 依赖
▼
┌─────────────────────────────────────────────────────────────┐
│ Model 层（数据模型层） │
│ - 数据库表结构定义 │
│ - 字段约束、索引、唯一性 │
└─────────────────────────────────────────────────────────────┘
```

**依赖规则**：

- 上层只能依赖相邻下层，不可跨层调用
- Service层不直接操作Model的QuerySet，通过Selector获取数据
- Serializer层只做数据转换，不做业务逻辑
- 所有业务异常通过Service层抛出，View层统一捕获并格式化

## 2. Selector层设计

### 2.1 Selector职责

1. 基础CRUD查询（单条查询、列表查询）
2. 复杂关联查询（JOIN、子查询、聚合）
3. 权限过滤（行级数据隔离）
4. 性能优化（select_related、prefetch_related）
5. 统计报表查询
6. 多条件动态筛选（`filter_by_query`）

### 2.2 Selector命名规范

| 类型       | 命名格式                           | 示例                           |
| :--------- | :--------------------------------- | :----------------------------- |
| 基础查询类 | `{Model}Selector`                  | `AssetSelector`                |
| 查询方法   | `get_{model}_by_recordcode()`      | `get_asset_by_recordcode()`    |
| 列表方法   | `list_{model}s()`                  | `list_assets()`                |
| 统计方法   | `count_{model}s()`                 | `count_assets()`               |
| 报表方法   | `report_{metric}_by_{dimension}()` | `report_assets_by_status()`    |
| 筛选方法   | `filter_by_query()`                | `filter_by_query(query, user)` |

### 2.3 AssetSelector 完整实现

```
python
from typing import Optional, List, Tuple, Dict
from django.db.models import QuerySet, Q, Count
from django.contrib.auth import get_user_model

from assets.models import Asset, OutAsset, RecycleAsset, AssetType
from departments.models import Department

AuthUser = get_user_model()


class AssetSelector:
    """资产数据查询器"""
    
    def get_asset_by_recordcode(
        self, 
        recordcode: str, 
        user: Optional[AuthUser] = None
    ) -> Optional[Asset]:
        """根据recordcode查询资产，自动预取关联数据"""
        queryset = Asset.objects.select_related(
            'asset_type_recordcode',
            'asset_contract_recordcode',
            'asset_storage_recordcode',
            'asset_entry_person_recordcode',
            'asset_applicant_recordcode',
            'asset_manager_recordcode'
        ).prefetch_related(
            'outasset_set',
            'repairasset_set',
            'assetstatelog_set'
        )
        queryset = self._apply_row_level_filter(queryset, user)
        return queryset.filter(recordcode=recordcode, is_deleted=False).first()
    
    def list_assets(
        self,
        user: Optional[AuthUser] = None,
        status: Optional[str] = None,
        asset_type: Optional[str] = None,
        storage: Optional[str] = None,
        manager: Optional[str] = None,
        search: Optional[str] = None,
        ordering: str = '-created_at',
        page: int = 1,
        page_size: int = 20
    ) -> Tuple[List[Asset], int]:
        """资产列表查询，支持过滤、排序、分页"""
        queryset = Asset.objects.select_related(
            'asset_manager_recordcode',
            'asset_storage_recordcode',
            'asset_type_recordcode'
        ).filter(is_deleted=False)
        
        queryset = self._apply_row_level_filter(queryset, user)
        
        # 过滤条件
        if status:
            queryset = queryset.filter(asset_current_status=status)
        if asset_type:
            queryset = queryset.filter(asset_type_recordcode=asset_type)
        if storage:
            queryset = queryset.filter(asset_storage_recordcode=storage)
        if manager:
            queryset = queryset.filter(asset_manager_recordcode=manager)
        if search:
            queryset = queryset.filter(
                Q(asset_code__icontains=search) |
                Q(asset_name__icontains=search) |
                Q(asset_brand__icontains=search)
            )
        
        # 排序
        queryset = queryset.order_by(ordering)
        
        # 分页
        total = queryset.count()
        start = (page - 1) * page_size
        queryset = queryset[start:start + page_size]
        
        return list(queryset), total
    
    def get_assets_by_manager(self, manager_recordcode: str) -> List[Asset]:
        """查询指定保管人管理的所有资产"""
        return Asset.objects.filter(
            asset_manager_recordcode=manager_recordcode,
            is_deleted=False
        ).select_related('asset_type_recordcode', 'asset_storage_recordcode')
    
    def get_assets_by_status(self, status: str) -> List[Asset]:
        """按状态查询资产"""
        return Asset.objects.filter(
            asset_current_status=status,
            is_deleted=False
        )
    
    def count_assets_by_status(self) -> Dict[str, int]:
        """按状态统计资产数量"""
        return dict(
            Asset.objects.filter(is_deleted=False)
            .values('asset_current_status')
            .annotate(count=Count('recordcode'))
            .values_list('asset_current_status', 'count')
        )
    
    def report_assets_by_type(self) -> List[Dict]:
        """按资产类型统计"""
        return list(
            Asset.objects.filter(is_deleted=False)
            .values('asset_type_recordcode__type_name')
            .annotate(count=Count('recordcode'))
            .order_by('-count')
        )
    
    def _apply_row_level_filter(self, queryset: QuerySet, user: Optional[AuthUser]) -> QuerySet:
        """应用行级数据隔离"""
        if not user:
            return queryset
        if user.is_superuser:
            return queryset
        # 非管理员只能查看本部门资产
        if hasattr(user, 'employee') and user.employee:
            dept = user.employee.employee_department
            if dept:
                dept_codes = [dept.department_code] + dept.get_all_descendants()
                return queryset.filter(
                    asset_manager_recordcode__employee_department__department_code__in=dept_codes
                )
        return queryset.none()
    
    # ========== 新增：资产类型全路径和树形 ==========
    def get_full_path(self, recordcode: str) -> Dict[str, str]:
        """获取资产类型的完整编码和名称路径"""
        node = AssetType.objects.filter(recordcode=recordcode, is_deleted=False).first()
        if not node:
            return None
        # 使用 path 字段一次性获取所有祖先，避免递归 N+1
        if not node.path:
            return {'full_code': node.type_code, 'full_name': node.type_name}
        codes = [c for c in node.path.split('/') if c]
        departments = {
            d.type_code: d
            for d in AssetType.objects.filter(type_code__in=codes, is_deleted=False)
        }
        full_codes = []
        full_names = []
        for code in codes:
            if code in departments:
                full_codes.append(departments[code].type_code)
                full_names.append(departments[code].type_name)
        return {
            'full_code': '-'.join(full_codes),
            'full_name': '-'.join(full_names)
        }
    
    def get_tree(self) -> List[Dict]:
        """获取资产类型树形结构（使用 parent FK 构建）"""
        all_types = AssetType.objects.filter(is_deleted=False).order_by('level', 'sort_order')
        # 构建节点映射（按 recordcode 索引）
        node_map = {}
        for t in all_types:
            node_map[t.recordcode] = {
                'recordcode': t.recordcode,
                'type_code': t.type_code,
                'type_name': t.type_name,
                'parent_type_code': t.parent.type_code if t.parent else None,
                'path': t.path,
                'level': t.level,
                'children': []
            }
        # 使用 parent FK 构建树
        roots = []
        for t in all_types:
            node = node_map[t.recordcode]
            if t.parent and t.parent.recordcode in node_map:
                node_map[t.parent.recordcode]['children'].append(node)
            else:
                roots.append(node)
        # 按sort_order排序子节点
        def sort_children(nodes):
            nodes.sort(key=lambda x: x.get('sort_order', 0))
            for node in nodes:
                if node['children']:
                    sort_children(node['children'])
        sort_children(roots)
        return roots
    
    # ========== 新增：多条件动态筛选 ==========
    def filter_by_query(self, query: Dict[str, Any], user: Optional[AuthUser] = None) -> QuerySet:
        """根据 query 对象动态构建资产筛选条件（AND逻辑）"""
        queryset = Asset.objects.filter(is_deleted=False).select_related(
            'asset_contract_recordcode',
            'asset_manager_recordcode__employee_department',
            'asset_storage_recordcode'
        )
        # 行级隔离
        queryset = self._apply_row_level_filter(queryset, user)
        
        # 构建 Q 对象
        q_conditions = Q()
        
        if query.get('asset_code'):
            q_conditions &= Q(asset_code__icontains=query['asset_code'])
        if query.get('asset_name'):
            q_conditions &= Q(asset_name__icontains=query['asset_name'])
        if query.get('asset_specification'):
            q_conditions &= Q(asset_specification__icontains=query['asset_specification'])
        if query.get('asset_brand'):
            q_conditions &= Q(asset_brand__icontains=query['asset_brand'])
        if query.get('contract_code'):
            q_conditions &= Q(asset_contract_recordcode__contract_code__icontains=query['contract_code'])
        if query.get('contract_name'):
            q_conditions &= Q(asset_contract_recordcode__contract_name__icontains=query['contract_name'])
        if query.get('asset_manager_jobcode'):
            q_conditions &= Q(asset_manager_recordcode__employee_jobcode=query['asset_manager_jobcode'])
        if query.get('asset_manager_name'):
            q_conditions &= Q(asset_manager_recordcode__employee_name__icontains=query['asset_manager_name'])
        if query.get('department_name'):
            q_conditions &= Q(asset_manager_recordcode__employee_department__department_name__icontains=query['department_name'])
        if query.get('asset_current_status'):
            q_conditions &= Q(asset_current_status=query['asset_current_status'])
        if query.get('usage_type'):
            q_conditions &= Q(usage_type=query['usage_type'])
        if query.get('storage_code'):
            q_conditions &= Q(asset_storage_recordcode__storage_code=query['storage_code'])
        if query.get('storage_name'):
            q_conditions &= Q(asset_storage_recordcode__storage_name__icontains=query['storage_name'])
        
        return queryset.filter(q_conditions)
```

```
class OutAssetSelector:
    """出库记录数据查询器"""
    
    def get_outasset_by_recordcode(self, recordcode: str) -> Optional[OutAsset]:
        return OutAsset.objects.select_related(
            'asset_recordcode',
            'outasset_applicant_recordcode',
            'outasset_manager_recordcode'
        ).filter(recordcode=recordcode).first()
    
    def list_outassets_by_asset(self, asset_recordcode: str) -> List[OutAsset]:
        """查询某资产的所有出库记录"""
        return OutAsset.objects.filter(
            asset_recordcode=asset_recordcode
        ).select_related(
            'outasset_applicant_recordcode',
            'outasset_manager_recordcode'
        ).order_by('-outasset_date')
    
    def get_active_outassets(self, asset_recordcode: str) -> Optional[OutAsset]:
        """查询资产当前有效的出库记录（未回收）"""
        return OutAsset.objects.filter(
            asset_recordcode=asset_recordcode
        ).exclude(
            recordcode__in=RecycleAsset.objects.filter(
                asset_recordcode=asset_recordcode
            ).values('outasset_recordcode')
        ).first()
    
    def list_recent_outassets(self, days: int = 30) -> List[OutAsset]:
        """查询最近N天的出库记录"""
        from django.utils import timezone
        from datetime import timedelta
        cutoff = timezone.now().date() - timedelta(days=days)
        return OutAsset.objects.filter(
            outasset_date__gte=cutoff
        ).select_related('asset_recordcode', 'outasset_applicant_recordcode')
    
    # ========== 新增：多条件筛选 ==========
    def filter_by_query(self, query: Dict[str, Any], user: Optional[AuthUser] = None) -> QuerySet:
        """出库记录动态筛选（示例）"""
        queryset = OutAsset.objects.filter(is_deleted=False).select_related(
            'asset_recordcode', 'outasset_applicant_recordcode', 'outasset_manager_recordcode'
        )
        # 可根据需要添加过滤字段，如 outasset_type、outasset_date 范围等
        q = Q()
        if query.get('outasset_type'):
            q &= Q(outasset_type=query['outasset_type'])
        if query.get('asset_code'):
            q &= Q(asset_recordcode__asset_code__icontains=query['asset_code'])
        # ... 其他字段
        return queryset.filter(q)
```

```
class EmployeeSelector:
    """员工数据查询器"""
    
    def get_employee_by_recordcode(self, recordcode: str) -> Optional[Employee]:
        return Employee.objects.select_related(
            'employee_department'
        ).filter(recordcode=recordcode, is_deleted=False).first()
    
    def get_employee_by_jobcode(self, jobcode: str) -> Optional[Employee]:
        return Employee.objects.select_related(
            'employee_department'
        ).filter(employee_jobcode=jobcode, is_deleted=False).first()
    
    def list_employees_by_department(
        self, 
        department_code: str, 
        include_sub: bool = True
    ) -> List[Employee]:
        """查询部门员工，可选择是否包含子部门"""
        queryset = Employee.objects.filter(is_deleted=False)
        if include_sub:
            dept = Department.objects.filter(
                department_code=department_code, 
                is_deleted=False
            ).first()
            if dept:
                dept_codes = [dept.department_code] + dept.get_all_descendants()
                queryset = queryset.filter(
                    employee_department__department_code__in=dept_codes
                )
        else:
            queryset = queryset.filter(
                employee_department__department_code=department_code
            )
        return queryset.select_related('employee_department')
    
    def get_active_employees(self) -> List[Employee]:
        """获取所有在职员工"""
        return Employee.objects.filter(
            employee_status='active',
            is_deleted=False
        ).select_related('employee_department')
    
    # ========== 新增：多条件筛选 ==========
    def filter_by_query(self, query: Dict[str, Any]) -> QuerySet:
        queryset = Employee.objects.filter(is_deleted=False).select_related('employee_department')
        q = Q()
        if query.get('employee_name'):
            q &= Q(employee_name__icontains=query['employee_name'])
        if query.get('employee_jobcode'):
            q &= Q(employee_jobcode=query['employee_jobcode'])
        if query.get('employee_status'):
            q &= Q(employee_status=query['employee_status'])
        if query.get('department_name'):
            q &= Q(employee_department__department_name__icontains=query['department_name'])
        return queryset.filter(q)
```

## 3. Service层设计

### 3.1 Service职责

- 事务管理（@transaction.atomic）
- 并发控制（select_for_update()）
- 状态机调用（AssetFSM）
- 关联记录创建
- 状态变更日志记录
- 异常处理
- 调用 Selector 进行数据查询和筛选

### 3.2 Service命名规范

| 类型       | 命名格式           | 示例              |
| :--------- | :----------------- | :---------------- |
| 业务服务类 | {Model}Service     | AssetService      |
| 核心方法   | {action}_{model}() | checkout_asset()  |
| 审批方法   | approve_{model}()  | approve_scrap()   |
| 取消方法   | cancel_{action}()  | cancel_checkout() |
| 筛选方法   | filter_{model}s()  | filter_assets()   |

### 3.3 AssetService 完整实现（含新增筛选和资产类型辅助方法）

```
python
from datetime import datetime
from typing import Dict, Any, Optional, List, Tuple
from django.db import transaction
from django.db.models import F

from assets.models import (
    Asset, OutAsset, RecycleAsset, BrokenAsset, 
    LostAsset, FoundAsset, RepairAsset, DamagedAsset, 
    WasteAsset, AssetType
)
from assets.audit import AuditLogger
from assets.fsm import AssetFSM, InvalidTransitionError
from assets.selectors import AssetSelector, OutAssetSelector
from assets.exceptions import BusinessRuleError
from departments.models import Employee


class AssetService:
    """资产业务服务"""
    
    def __init__(self):
        self.asset_selector = AssetSelector()
        self.out_asset_selector = OutAssetSelector()
        self.fsm = AssetFSM()
    
    @transaction.atomic
    def create_asset(self, data: Dict[str, Any]) -> Asset:
        """创建资产"""
        from assets.serializers import AssetCreateSerializer
        serializer = AssetCreateSerializer(data=data)
        serializer.is_valid(raise_exception=True)
        asset = serializer.save(
            asset_current_status='in_store',
            usage_type='new',
            physical_grade='good',
            version=1
        )
        AuditLogger.log_asset_create(
            asset=asset,
            operator_jobcode=data.get('operator_jobcode'),
            operator_name=data.get('operator_name')
        )
        return asset
    
    @transaction.atomic
    def checkout_asset(
        self,
        asset_recordcode: str,
        data: Dict[str, Any],
        operator: Employee
    ) -> OutAsset:
        """
        资产出库
        使用悲观锁防止并发冲突
        """
        from assets.serializers import OutAssetCreateSerializer
        
        # 使用select_for_update加锁
        asset = Asset.objects.select_for_update().get(
            recordcode=asset_recordcode,
            is_deleted=False
        )
        
        if asset.asset_current_status not in ['in_store', 'recycled_pending']:
            raise InvalidTransitionError(
                f"资产状态({asset.asset_current_status})不允许出库"
            )
        
        previous_status = asset.asset_current_status
        
        # 创建出库记录
        out_serializer = OutAssetCreateSerializer(data=data)
        out_serializer.is_valid(raise_exception=True)
        out_asset = out_serializer.save(
            asset_recordcode=asset,
            outasset_previous_status=previous_status
        )
        
        # 调用状态机
        self.fsm.outasset(asset)
        asset.save()
        
        # 更新资产字段
        if 'outasset_applicant_recordcode' in data:
            asset.asset_applicant_recordcode_id = data['outasset_applicant_recordcode']
        if 'outasset_manager_recordcode' in data:
            asset.asset_manager_recordcode_id = data['outasset_manager_recordcode']
        if 'outasset_using_location' in data:
            asset.asset_using_location = data['outasset_using_location']
        asset.save()
        
        # 创建状态日志
        AuditLogger.log_state_change(
            asset=asset,
            from_state=previous_status,
            to_state='in_use',
            trigger=f'出库：{out_asset.outasset_type}',
            operator_jobcode=operator.employee_jobcode,
            operator_name=operator.employee_name
        )
        
        return out_asset
    
    @transaction.atomic
    def recycle_asset(
        self,
        asset_recordcode: str,
        data: Dict[str, Any],
        operator: Employee
    ) -> RecycleAsset:
        """资产回收"""
        from assets.serializers import RecycleAssetCreateSerializer
        
        asset = Asset.objects.select_for_update().get(
            recordcode=asset_recordcode,
            is_deleted=False
        )
        
        if asset.asset_current_status != 'in_use':
            raise InvalidTransitionError(
                f"资产状态({asset.asset_current_status})不允许回收"
            )
        
        # 查找对应的出库记录
        out_asset = self.out_asset_selector.get_active_outassets(asset_recordcode)
        if not out_asset:
            raise BusinessRuleError("资产没有未回收的出库记录")
        
        # 创建回收记录
        recycle_serializer = RecycleAssetCreateSerializer(data=data)
        recycle_serializer.is_valid(raise_exception=True)
        recycle = recycle_serializer.save(
            asset_recordcode=asset,
            outasset_recordcode=out_asset,
            operator_employee=operator
        )
        
        # 调用状态机
        self.fsm.recycle(asset)
        asset.save()
        
        # 清理资产字段
        asset.asset_manager_recordcode = None
        asset.asset_using_location = ''
        asset.save()
        
        # 如果回收时发现损坏
        if data.get('is_broken'):
            self._mark_broken_asset(asset, data, operator)
        
        # 如果回收时发现遗失
        if data.get('is_lost'):
            self._mark_lost_asset(asset, data, operator)
        
        # 创建状态日志
        AuditLogger.log_state_change(
            asset=asset,
            from_state='in_use',
            to_state='recycled_pending',
            trigger='资产回收',
            operator_jobcode=operator.employee_jobcode,
            operator_name=operator.employee_name
        )
        
        return recycle
    
    @transaction.atomic
    def start_repair(
        self,
        asset_recordcode: str,
        data: Dict[str, Any],
        operator: Employee
    ) -> RepairAsset:
        """资产送修"""
        from assets.serializers import RepairAssetCreateSerializer
        
        asset = Asset.objects.select_for_update().get(
            recordcode=asset_recordcode,
            is_deleted=False
        )
        
        if asset.asset_current_status != 'broken':
            raise InvalidTransitionError(
                f"资产状态({asset.asset_current_status})不允许送修"
            )
        
        # 记录维修前物理成色
        data['physical_grade_before'] = asset.physical_grade
        
        # 创建维修记录
        repair_serializer = RepairAssetCreateSerializer(data=data)
        repair_serializer.is_valid(raise_exception=True)
        repair = repair_serializer.save(
            asset_recordcode=asset,
            repair_status='in_progress',
            operator_employee=operator
        )
        
        # 调用状态机
        self.fsm.start_repair(asset)
        asset.save()
        
        # 创建状态日志
        AuditLogger.log_state_change(
            asset=asset,
            from_state='broken',
            to_state='repairing',
            trigger='送修',
            operator_jobcode=operator.employee_jobcode,
            operator_name=operator.employee_name
        )
        
        return repair
    
    @transaction.atomic
    def complete_repair(
        self,
        repair_recordcode: str,
        data: Dict[str, Any],
        operator: Employee
    ) -> RepairAsset:
        """维修完成"""
        from assets.serializers import RepairAssetUpdateSerializer
        
        repair = RepairAsset.objects.select_for_update().get(
            recordcode=repair_recordcode
        )
        asset = repair.asset_recordcode
        
        if asset.asset_current_status != 'repairing':
            raise InvalidTransitionError("资产不在维修中状态")
        
        # 更新维修记录
        update_serializer = RepairAssetUpdateSerializer(
            instance=repair,
            data=data,
            partial=True
        )
        update_serializer.is_valid(raise_exception=True)
        repair = update_serializer.save()
        repair.repair_status = 'completed'
        repair.actual_return_date = data.get('actual_return_date', datetime.now().date())
        repair.save()
        
        # 调用状态机
        self.fsm.repair_done(asset)
        asset.save()
        
        # 更新资产物理成色
        if data.get('physical_grade_after'):
            asset.physical_grade = data['physical_grade_after']
            asset.save()
        
        # 创建状态日志
        AuditLogger.log_state_change(
            asset=asset,
            from_state='repairing',
            to_state='recycled_pending',
            trigger='维修完成',
            operator_jobcode=operator.employee_jobcode,
            operator_name=operator.employee_name
        )
        
        return repair
    
    @transaction.atomic
    def apply_scrap(
        self,
        asset_recordcode: str,
        data: Dict[str, Any],
        operator: Employee
    ) -> DamagedAsset:
        """申请报废"""
        from assets.serializers import DamagedAssetCreateSerializer
        
        asset = Asset.objects.select_for_update().get(
            recordcode=asset_recordcode,
            is_deleted=False
        )
        
        allowed_statuses = ['broken', 'lost', 'in_use', 'recycled_pending']
        if asset.asset_current_status not in allowed_statuses:
            raise InvalidTransitionError(
                f"资产状态({asset.asset_current_status})不允许申请报废"
            )
        
        original_status = asset.asset_current_status
        
        # 创建报废申请
        damaged_serializer = DamagedAssetCreateSerializer(data=data)
        damaged_serializer.is_valid(raise_exception=True)
        damaged = damaged_serializer.save(
            asset_recordcode=asset,
            approval_status='pending',
            original_status=original_status
        )
        
        # 调用状态机
        self.fsm.damaged(asset)
        asset.save()
        
        # 创建状态日志
        AuditLogger.log_state_change(
            asset=asset,
            from_state=original_status,
            to_state='damaged',
            trigger='提交报废申请',
            operator_jobcode=operator.employee_jobcode,
            operator_name=operator.employee_name
        )
        
        return damaged
    
    @transaction.atomic
    def approve_scrap(
        self,
        damaged_recordcode: str,
        approver: Employee
    ) -> WasteAsset:
        """报废审批通过"""
        damaged = DamagedAsset.objects.select_for_update().get(
            recordcode=damaged_recordcode
        )
        
        if damaged.approval_status != 'pending':
            raise BusinessRuleError("该申请已处理，不可重复审批")
        
        asset = damaged.asset_recordcode
        
        # 创建报废记录
        waste = WasteAsset.objects.create(
            asset_recordcode=asset,
            damaged_recordcode=damaged,
            waste_asset_date=datetime.now().date()
        )
        
        # 更新申请状态
        damaged.approval_status = 'approved'
        damaged.approver = approver
        damaged.save()
        
        # 调用状态机
        self.fsm.approve(asset)
        asset.save()
        
        # 创建状态日志
        AuditLogger.log_state_change(
            asset=asset,
            from_state='damaged',
            to_state='scrapped',
            trigger='报废审批通过',
            operator_jobcode=approver.employee_jobcode,
            operator_name=approver.employee_name
        )
        
        return waste
    
    @transaction.atomic
    def reject_scrap(
        self,
        damaged_recordcode: str,
        approver: Employee,
        remark: str = ''
    ) -> DamagedAsset:
        """报废审批拒绝"""
        damaged = DamagedAsset.objects.select_for_update().get(
            recordcode=damaged_recordcode
        )
        
        if damaged.approval_status != 'pending':
            raise BusinessRuleError("该申请已处理，不可重复审批")
        
        asset = damaged.asset_recordcode
        original_status = damaged.original_status
        
        # 更新申请状态
        damaged.approval_status = 'rejected'
        damaged.approver = approver
        damaged.save()
        
        # 调用状态机（恢复到原状态）
        if original_status == 'broken':
            self.fsm.reject_to_broken(asset)
        elif original_status == 'lost':
            self.fsm.reject_to_lost(asset)
        else:
            self.fsm.reject(asset)
        asset.save()
        
        # 创建状态日志
        AuditLogger.log_state_change(
            asset=asset,
            from_state='damaged',
            to_state=original_status,
            trigger=f'报废审批拒绝：{remark}',
            operator_jobcode=approver.employee_jobcode,
            operator_name=approver.employee_name
        )
        
        return damaged

    def filter_assets(
```

## 4. 通用筛选支持说明

为统一前端调用方式，系统为所有核心资源（Asset、Contract、Storage、Department、Employee、OutAsset、RecycleAsset、BrokenAsset、LostAsset、RepairAsset、DamagedAsset、UnregisteredAsset 等）均提供 `/filter/` 端点。其统一特征如下：

- **请求方法**：POST
- **请求体**：`{"query": {...}}`，其中 `query` 为筛选条件对象，各字段的匹配方式（精确/模糊）见各模型对应的 `FilterSerializer` 定义。
- **响应**：对应的 `ListSerializer` 列表，支持分页。
- **权限**：遵循 RBAC 和行级数据隔离规则。
- **空查询**：若 `query` 为空对象 `{}`，返回所有未删除记录（`is_deleted=False`），按默认排序。

各模型 Selector 均实现 `filter_by_query` 方法，内部使用 `Q` 对象动态构建查询，并利用 `select_related`/`prefetch_related` 优化性能。
