## 一、项目理解（第一轮输出，存档）

- **架构**：前后端分离。后端 Django 6 + DRF 3.16 + PostgreSQL + SimpleJWT + drf-spectacular，五层架构 Model → Selector → Service → Serializer → View；前端 Vue 3 + Element Plus + Vite + TS + Pinia 3（`vue-assetmanagement/` 子模块）。
- **核心业务**：资产全生命周期（入库/领用/外借/回收/损坏/遗失/报废/维修/找回）+ 未登记资产 + 部门/员工/角色管理 + 通知 + 审计。
- **治理体系**：Root Engine v3.5.1（CT/DR/SC/OC/AR/Fact/Style 七组契约）+ 活账本 `Rules_Fiels/Duplicate_Codes/complete-patterns.md` + 三个守卫脚本（G-1~G-5 / BR-4 / FR-6+FR-8）。
- **端点规模**：`/api/v1/` 下 auth、users、assets、unregisteredassets、dashboard、notifications 六大路由域 + `/health/`、`/ready/`、`/metrics/` 三个运维端点（`config/urls.py:145-166`）。
