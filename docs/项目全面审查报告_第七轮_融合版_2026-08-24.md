## 四、安全审查

### 4.1 HTTPS/HSTS ⚠️
- HTTPS 强制(nginx 301 + SECURE_SSL_REDIRECT)、TLS1.2/1.3、OCSP ✓
- 🔶 **HSTS 双下发待治理**(方案已审)：Django 1年 vs Nginx 2年并存；且兄弟头(nosniff/x-frame/referrer-policy)因 Django 默认值仍在重复下发、Referrer-Policy 存在值冲突。方案：安全头归属统一归 Nginx(Django 显式关闭发射)
### 4.2 身份鉴权 ✅
- JWT cookie+bearer 双通道、登录限流、RBAC Permission+QuerySet 双过滤、superuser 快捷路径 ✓
- 注意：JWT 与 SECRET_KEY 共用密钥，轮换 SECRET_KEY 会使全部 token 失效(运维须知)
### 4.3 输入校验 ✅（纯 ORM 零 raw、DRF 强校验、escapeHtml、CSP）
### 4.4 安全头 ⚠️（同 4.1 待治理；X-XSS-Protection 已弃用头可移除）
### 4.5 Redis ⚠️ P1
- 未设 requirepass，仅依赖内网隔离——横向移动风险，建议加密码并同步 CHANNEL_LAYERS 配置
### 4.6 Docker ✅（appuser 非 root、敏感变量 `:?` 强制、端口 loopback、资源限制；cap_drop/read_only 未配置登记 P2）
