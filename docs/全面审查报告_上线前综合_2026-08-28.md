### 10.2 复核发现的错误断言

#### ❌ E-1（阻断级，方向性错误）：§2.1/§2.2「生产 API 与 token 密钥由 CI/CD 构建时注入」不成立

- 全仓搜索 `*.yml` / `*.tpl` / `Dockerfile` / `*.sh`：**零处** `VITE_*` 注入机制。

- 生产前端由 `docker-compose.yml:118-121` 的 nginx 服务构建（`docker/nginx/Dockerfile`），构建上下文为仓库根。
- **关键新状态**（`docker/nginx/Dockerfile:10-15`，未提交，属 R-2 的 19 项之一）：

  ```dockerfile
  # F-1 门禁(2026-08-26): 构建前强制校验环境变量完整性。
  # 缺 VITE_TOKEN_CRYPTO_KEY 时直接失败, 防止产出首屏白屏的生产包。
  # 密钥经文件通道注入(S2决策): CI 部署前将真实值写入 .env.production.local ...
  ```
