### 4.2 unregisteredasset失败分析

失败原因与本次修复无关，是已有问题：

1. **API测试失败（13个）**：
   - 原因：`'Employee' object has no attribute 'is_authenticated'`
   - 说明：测试中使用了Employee对象而不是AuthUser对象进行认证

2. **服务测试失败（4个）**：
   - 原因：`RecycleAsset() got unexpected keyword arguments: 'asset_recordcode_number'`
   - 说明：RecycleAsset模型字段名与测试数据不匹配

3. **模型测试失败（1个）**：
   - 原因：唯一约束测试
   - 说明：MySQL不支持条件唯一约束
