## 二、已完成的修复

### 2.1 Asset模型修复

| 修改项 | 变更前 | 变更后 | 说明 |
|:---|:---|:---|:---|
| RECORDCODE_PREFIX | `"ENTRY"` | `"ASSET"` | 符合文档要求 |
| usage_type字段 | 不存在 | `Char(20), default="new"` | 新增使用性质字段 |
| physical_grade字段 | 不存在 | `Char(20), default="good"` | 新增物理成色字段 |
| qr_code字段 | 不存在 | `Char(200), null=True` | 新增二维码字段 |
| asset_type_recordcode on_delete | DO_NOTHING | PROTECT | 防止删除被引用的类型 |
| asset_storage_recordcode on_delete | DO_NOTHING | PROTECT | 防止删除被引用的仓库 |
| asset_applicant_recordcode on_delete | DO_NOTHING | SET_NULL | 申请人删除后置空 |
| asset_manager_recordcode on_delete | DO_NOTHING | SET_NULL | 保管人删除后置空 |
| asset_code唯一约束 | 全局unique | 条件唯一(is_deleted=False) | 软删除后可重复 |
| qr_code唯一约束 | 不存在 | 条件唯一(is_deleted=False) | 保证二维码唯一 |
| ASSET_STATUS_CHOICES | 无repairing | 新增repairing | 支持维修状态 |

### 2.2 OutAsset模型修复

| 修改项 | 变更前 | 变更后 |
|:---|:---|:---|
| RECORDCODE_PREFIX | `"OUT"` | `"OUTASSET"` |
| asset_recordcode on_delete | SET_NULL | PROTECT |
| asset_recordcode nullable | null=True | 必填 |

### 2.3 RecycleAsset模型修复

| 修改项 | 变更前 | 变更后 |
|:---|:---|:---|
| is_broken字段 | 存在 | 已移除（文档废弃） |
| is_lost字段 | 存在 | 已移除（文档废弃） |
| operator_employee on_delete | DO_NOTHING | SET_NULL |

### 2.4 BrokenAsset模型修复

| 修改项 | 变更前 | 变更后 |
|:---|:---|:---|
| asset_recordcode类型 | OneToOneField | ForeignKey |
| asset_recordcode on_delete | SET_NULL | PROTECT |
| asset_recordcode nullable | null=True | 必填 |

### 2.5 LostAsset模型修复

| 修改项 | 变更前 | 变更后 |
|:---|:---|:---|
| asset_recordcode类型 | OneToOneField | ForeignKey |
| asset_recordcode on_delete | SET_NULL | PROTECT |
| asset_recordcode nullable | null=True | 必填 |

### 2.6 DamagedAsset模型修复

| 修改项 | 变更前 | 变更后 |
|:---|:---|:---|
| asset_recordcode on_delete | SET_NULL | PROTECT |
| asset_recordcode nullable | null=True | 必填 |
| approver on_delete | DO_NOTHING | SET_NULL |

### 2.7 RepairAsset模型创建

新建维修记录模型，包含以下字段：
- asset_recordcode (FK Asset, PROTECT)
- repair_date (Date)
- repair_reason (Text)
- repair_status (Char, choices: in_progress/completed/failed)
- expected_completion_date (Date, nullable)
- actual_completion_date (Date, nullable)
- physical_grade_before (Char)
- physical_grade_after (Char, nullable)
- repair_description (Text, nullable)
- version (Integer)
