## 五、遗留问题

### 5.1 MySQL条件唯一约束警告

```
WARNING: MySQL does not support unique constraints with conditions.
```

**说明**：MySQL不支持条件唯一约束，Django会在数据库层面创建普通索引而非唯一约束。这是MySQL的限制，不影响功能，但需要在应用层处理并发创建相同编码的情况。

### 5.2 后续优化（阶段四）

以下模型与文档差异较大，建议在后续版本中处理：

1. **AssetType**：字段名大量不同（asset_type_code→type_code等）
2. **Storage**：缺少storage_manager、storage_capacity字段
3. **Contract**：20+处字段名/类型不同，需要完全重构
