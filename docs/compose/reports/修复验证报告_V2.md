### 2.2 authusermanagement模型冲突修复
**问题**：AuthUser和Django内置User都继承了PermissionsMixin，related_name="user_set"冲突

**修复方案**：在AuthUser模型中覆盖groups和user_permissions字段，使用自定义的related_name

**修改的文件**：`authusermanagement/models.py`
```python
groups = models.ManyToManyField(
    'auth.Group',
    verbose_name='groups',
    blank=True,
    help_text='The groups this user belongs to.',
    related_name='authuser_set',
    related_query_name='authuser',
)
user_permissions = models.ManyToManyField(
    'auth.Permission',
    verbose_name='user permissions',
    blank=True,
    help_text='Specific permissions for this user.',
    related_name='authuser_set',
    related_query_name='authuser',
)
```
