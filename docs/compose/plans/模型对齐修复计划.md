### 任务1.7：创建RepairAsset模型

**目标**：创建缺失的RepairAsset模型

**文件**：`asset_management_backend/apps/assetmanagement/models/repair_asset.py`

**新建内容**：
```python
class RepairAsset(BaseModel):
    RECORDCODE_PREFIX = "REPAIR"
    
    asset_recordcode = models.ForeignKey(
        'assetmanagement.Asset',
        to_field="recordcode",
        on_delete=models.PROTECT,
        related_name="repair_assets",
        verbose_name="维修资产"
    )
    repair_date = models.DateField(verbose_name="送修日期")
    repair_reason = models.TextField(verbose_name="维修原因")
    repair_status = models.CharField(
        max_length=20,
        choices=[('in_progress', '维修中'), ('completed', '已完成'), ('failed', '失败')],
        default='in_progress',
        verbose_name="维修状态"
    )
    expected_completion_date = models.DateField(null=True, blank=True, verbose_name="预计完成日期")
    actual_completion_date = models.DateField(null=True, blank=True, verbose_name="实际完成日期")
    physical_grade_before = models.CharField(max_length=20, verbose_name="维修前成色")
    physical_grade_after = models.CharField(max_length=20, null=True, blank=True, verbose_name="维修后成色")
    repair_description = models.TextField(null=True, blank=True, verbose_name="维修描述")
    version = models.IntegerField(default=1, verbose_name="版本号")
```
